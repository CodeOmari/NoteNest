# NoteNest
A full-stack note-taking application built with React, Bootstrap, Django REST Framework, and MySQL. It allows users to create, organize, edit, and manage personal notes through a rich-text editor. Features include secure JWT authentication, password reset via email, and scheduled email reminders to help users stay on top of important notes.

# Tech Stack
The following languages are used in this project: HTML, JavaScript(React), CSS and Python(Django Rest Framework).

# Project Setup
1. Clone the project: `git clone https://github.com/CodeOmari/NoteNest.git`
2. Open the project in your code editor.
3. In your editor, open terminal and change to the frontend directory: `cd backend`, `cd frontend`
4. Install all the frontend dependencies: `npm install`
5. Change directory to the main folder of the project: `cd ..`
6. Install virtual environment: `python -m venv venv` or `python3 -m venv venv` - Linux users
7. Activate virtual environment: `venv/Scripts/activate` or `source venv/bin/activate` - Linux users
8. Change directory to the backend folder: `cd backend`
9. Install project requirements from the requirements.txt file: `pip install -r requirements.txt`
10. Run the backend of the project: `python manage.py runserver`
11. Open a new terminal and navigate to the frontend directory: `cd ..`, `cd frontend`
12. Run frontend of the project: `npm run dev`
